# 命名记录：Diorama

> 记录于 2026-10-18。

**目标**：一个在任意目录启动、用浏览器浏览文件的 CLI。能力通过插件扩展：语法高亮、Markdown 渲染、git diff，以及之后更多。名字不能是 `http-file-server` 这类把功能写死的名字，也不能只讲"可扩展"而丢了"能看见东西"。

## 结论

**Diorama**，命令 `diorama`。

中间试过两个方向：中文神话（天吴、重明、烛龙、白泽）和首字母缩写（Peruse、Reframe、Reveal 等）。前者 GitHub 组织名要么被个人账号占用、要么被 GitHub 保留；后者查下来也基本都有同名。最终回到第一版名字，组织名改用 `diorama-cli`。

## 词源

希腊语 **dia-**（穿过）+ **horama**（所见，来自 *horan*，"看"），字面意思是"透过一个窗口看到的景象"。

1822 年 Louis Daguerre 在巴黎展出的同名装置，让观众坐进暗室，观看巨幅画面在自然光变化中"活"起来，通常被视为电影的前身。这个词从诞生起就指**一台把景象呈现给你看的机器**。

## 两层含义

| 层 | 含义 | 对应产品 |
|---|---|---|
| 功能 | 一个可以看进去的场景 | 浏览器里浏览目录；文件按类型渲染 |
| 扩展 | 场景由一块块景片搭成 | 每个插件是一块 **piece**；装得越多，场景越完整 |

关键点：**插件不是"附加功能"，而是画面本身的组成部分**。所以名字不需要额外声明"可扩展"——它本来就是一个由许多块组成的东西。

## 候选对比

| 名字 | 两层意思 | 落选原因 |
|---|---|---|
| Prism | 白光散成光谱，最贴切 | Prism.js 就是语法高亮库，等于用被渲染对象的名字命名渲染器 |
| Kaleidoscope | 转动碎片、重组画面 | macOS 上的 diff/对比工具，与 git diff 正面冲突 |
| Mosaic | 马赛克，最完美 | 第一个被广泛使用的图形浏览器，历史包袱太重 |
| Lens | 换镜头换视角 | Lens 是 Kubernetes IDE |
| Panoply | 盛大陈列／整套装备 | 可作备选；已有一家数据平台公司同名 |
| Oriel | 向外凸出的窗：延伸 + 视野 | 可作备选；偏冷僻，口语里容易听成 Ariel |
| Facet | 宝石的面：一个文件有很多面 | 可作备选；facet-rs 已 2.6k star，且 facet 在 UI/搜索里太通用 |
| Tessera | 马赛克的一块瓷砖 | 只说了"零件"，没说"画面"，也没有功能含义 |
| Banyan | 榕树，独木成林 | 只说了"生长"，丢了"看见" |

## 撞名检查（2026-10-17）

- npm `diorama`：2.0.21，一个 24 star 的 React 展示组件（mendrik/diorama），不是 CLI，也不是文件浏览器。
- GitHub 同名仓库：最大 59 star（3dlg-hcvc/diorama，3D 场景建模论文代码），其余均低于 60 star。
- 同赛道（CLI／文件服务／浏览器）未发现同名项目。

## 命名自检

念出名字时，第一反应应该是"哦，我能看见东西"，第二反应才是"哦，它能往上长"。Diorama 满足前者，也满足后者。

## 品牌小件

- 命令：`diorama`
- 配置：`diorama.toml`
- 插件：**piece**（一块景片）
- 一组插件：**scene**
- Slogan：A live diorama of your files. / 把你的目录，摆成一个场景。
