# 命名记录：Tianwu

> 记录于 2026-10-18。

**目标**：一个在任意目录启动、用浏览器浏览文件的 CLI。能力通过插件扩展：语法高亮、Markdown 渲染、git diff，以及之后更多。名字不能是 `http-file-server` 这类把功能写死的名字，也不能只讲"可扩展"而丢了"能看见东西"。

## 结论

**Tianwu**，命令 `tianwu`。

## 出处

《山海经·海外东经》："朝阳之谷，神曰天吴，是为水伯。……其为兽也，八首人面，八足八尾，皆青黄。"

一个身体，八张脸，八个方向。八是虚指，代表"多"。

## 两层含义

| 层 | 含义 | 对应产品 |
|---|---|---|
| 功能 | 一张脸朝一个方向，一次看见八方 | 浏览器里浏览目录；文件按类型渲染成不同视图 |
| 扩展 | 每装一个插件，多一张脸 | 每个插件是一个 **face**；插件越多，看见的越多 |

关键点：**功能和扩展长在同一个形象上**。天吴不是"一个后来学会新技能的东西"，而是"天生就有很多张脸的东西"。

## 候选对比

| 名字 | 出处 | 故事 | 落选原因 |
|---|---|---|---|
| Chongming 重明 | 《拾遗记》 | 重明鸟又名"双睛"，每目双瞳；双瞳 = 源码 + 渲染 | 故事最准，但 GitHub handle 被个人账号占用，且与"崇明"同音 |
| Zhulong 烛龙 | 《山海经·大荒北经》 | 睁眼为昼、闭眼为夜 | 最有气势，但"多"的映射弱 |
| Baize 白泽 | 白泽图 | 知道万物名字与形态 | 5 字母最短，但 2023 年有个同名开源聊天模型，npm 也被占 |
| Diorama | 希腊语 dia- + horama | 透过窗口看到的景象 | 初版名字；GitHub 组织 diorama 已存在 |
| Banyan | 榕树 | 独木成林 | 只讲生长，丢了"看见" |
| Tessera | 马赛克瓷砖 | 一块块拼出画面 | 只讲零件，不讲画面 |

## 撞名检查（2026-10-18）

- GitHub `tianwu`：空（`github.com/tianwu` → 404）。
- npm `tianwu`：空。
- 短拼音名（chongming / zhulong / baize / kaiming / lizhu / xuanji …）在 GitHub 上几乎都被个人账号占用，Tianwu 是少数空着的。
- 同赛道（CLI / 文件服务 / 浏览器）未发现同名项目。

## 命名自检

念出名字时，第一反应应该是"我能看见东西"，第二反应才是"它能长出更多脸"。Tianwu 两句都成立。

## 品牌小件

- 命令：`tianwu`
- 配置：`tianwu.toml`
- 插件：**face**（一张脸 = 一种看法）
- Slogan：One directory, eight faces. / 一个目录，八张脸。
