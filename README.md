# Tianwu

> One directory, eight faces.

在任意目录执行一条命令，这个目录就变成浏览器里一个可以走进去看的场景。代码文件有语法高亮，Markdown 会被渲染，之后还会有 git diff——每一样能力都是天吴的一张脸，装上插件就多一张。

**状态**：命名已定，代码未开始。

## 为什么叫 Tianwu

《山海经·海外东经》："朝阳之谷，神曰天吴，是为水伯。……其为兽也，八首人面，八足八尾，皆青黄。"

天吴是一个身体、八张脸的神兽，八张脸朝向八个方向，一次看见八方。八在中文里是虚指——是"多"，不是上限。

这个名字同时说了两件事：

- **你能看见什么**：一张脸看一个方向。同一个目录，源码、渲染、diff，是不同脸看到的东西。
- **它是怎么长大的**：每装一个插件，就多一张脸。

它不是"一个能扩展的文件服务器"，而是"一个天生就有很多张脸的东西"——功能和扩展长在同一个形象上。

## 品牌小件

| 项 | 值 |
|---|---|
| 命令 | `tianwu` |
| 配置 | `tianwu.toml` |
| 插件 | **face**（一张脸 = 一种看法） |
| Slogan | One directory, eight faces. / 一个目录，八张脸。 |

```bash
tianwu .                 # 目录 → 浏览器里的八张脸
tianwu --port 8080
```
